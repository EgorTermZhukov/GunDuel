## Project features: 
- Model-View approach that separates data from visuals
- Event-driven interaction framework using interfaces and reflection for attaching logic to data
- Sequencing using unity coroutines
- Modular and decoupled systems that allow for flexible extension and integration of new behaviors
- Uses DOTween for good-looking animations wired through code 
- Custom tick system for managing timed events and interactions
